# 📖 Learn the Basics

Welcome to the **Learn the Basics** module of Python Gym! This series covers Python fundamentals through 7 hands-on interactive Jupyter notebooks.

---

## 📚 Notebook Directory

| # | Notebook | Focus Area | Key Topics Covered |
|---|----------|------------|--------------------|
| 1 | [basic_syntax.ipynb](file:///e:/repositories/python_gym/learn_the_basics/basic_syntax.ipynb) | Basic Syntax | Indentation, line continuation, comments, `print()`, `input()`, Python keywords |
| 2 | [variables_and_data_types.ipynb](file:///e:/repositories/python_gym/learn_the_basics/variables_and_data_types.ipynb) | Variables & Types | Dynamic typing, primitive types (`int`, `float`, `bool`, `str`), collections (`list`, `tuple`, `dict`, `set`), type casting |
| 3 | [operators.ipynb](file:///e:/repositories/python_gym/learn_the_basics/operators.ipynb) | Operators | Arithmetic, comparison, logical, bitwise, membership (`in`), identity (`is`), precedence, walrus operator `:=` |
| 4 | [control_flow.ipynb](file:///e:/repositories/python_gym/learn_the_basics/control_flow.ipynb) | Control Flow | `if/elif/else`, `match/case` pattern matching, `for`/`while` loops, loop `else` clauses, `break`, `continue` |
| 5 | [working_with_strings.ipynb](file:///e:/repositories/python_gym/learn_the_basics/working_with_strings.ipynb) | String Manipulation | Indexing, slicing, f-strings, string methods, raw strings, UTF-8 bytes conversion |
| 6 | [loops.ipynb](file:///e:/repositories/python_gym/learn_the_basics/loops.ipynb) | Loops Deep Dive | Iterables, `range()`, `enumerate()`, `zip()`, nested loops, comprehension vs generator performance |
| 7 | [functions.ipynb](file:///e:/repositories/python_gym/learn_the_basics/functions.ipynb) | Functions | Functions, `*args`, `**kwargs`, positional/keyword markers (`/`, `*`), closures, decorators intro, recursion |

Launch Jupyter Lab in the root directory:
