# 📖 Learn the Basics

Welcome to the **Learn the Basics** module of Python Gym! This series covers Python fundamentals through 18 hands-on interactive Jupyter notebooks.

---

## 📚 Notebook Directory

| # | Notebook | Focus Area | Key Topics Covered |
|---|----------|------------|--------------------|
| 1 | [basic_syntax.ipynb](basic_syntax.ipynb) | Basic Syntax | Indentation, line continuation, comments, `print()`, `input()`, Python keywords |
| 2 | [variables_and_data_types.ipynb](variables_and_data_types.ipynb) | Variables & Types | Dynamic typing, primitive types (`int`, `float`, `bool`, `str`), collections overview, type introspection |
| 3 | [operators.ipynb](operators.ipynb) | Operators | Arithmetic, comparison, logical, bitwise, membership (`in`), identity (`is`), precedence, walrus operator `:=` |
| 4 | [control_flow.ipynb](control_flow.ipynb) | Control Flow | `if/elif/else`, `match/case` pattern matching, `for`/`while` loops, loop `else` clauses, `break`, `continue` |
| 5 | [working_with_strings.ipynb](working_with_strings.ipynb) | String Manipulation | Indexing, slicing, f-strings, string methods, raw strings, UTF-8 bytes conversion |
| 6 | [loops.ipynb](loops.ipynb) | Loops Deep Dive | Iterables, `range()`, `enumerate()`, `zip()`, nested loops, comprehension vs generator performance |
| 7 | [functions.ipynb](functions.ipynb) | Functions | Functions, `*args`, `**kwargs`, positional/keyword markers (`/`, `*`), closures, decorators intro, recursion |
| 8 | [lists.ipynb](lists.ipynb) | Lists Deep Dive | Dynamic arrays, multi-stride slicing, in-place methods, list comprehensions intro, memory growth, copying |
| 9 | [tuples.ipynb](tuples.ipynb) | Tuples & NamedTuples | Immutability, packing, extended unpacking (`*rest`), struct caching, `NamedTuple` |
| 10 | [sets.ipynb](sets.ipynb) | Sets & FrozenSets | Set theory, mathematical operators (`\|`, `&`, `-`, `^`), $O(1)$ lookups, `frozenset` |
| 11 | [dictionaries.ipynb](dictionaries.ipynb) | Dictionaries Deep Dive | Hash maps, dict views, merge operators (`\|`, `\|=`), `defaultdict`, `Counter` |
| 12 | [type_casting.ipynb](type_casting.ipynb) | Type Casting & Conversions | Implicit vs. explicit conversions, truthiness, numeric bases, dunder conversion protocols |
| 13 | [exceptions.ipynb](exceptions.ipynb) | Exception Handling | `try/except/else/finally`, custom exceptions, exception chaining (`raise from`), `ExceptionGroup`, EAFP vs. LBYL |
| 14 | [type_annotations.ipynb](type_annotations.ipynb) | Type Annotations | Modern type hints (`int \| str`), Generics, `TypedDict`, `Protocol`, `Callable`, `TypeVar` |
| 15 | [list_comprehensions.ipynb](list_comprehensions.ipynb) | List Comprehensions | Syntax anatomy, conditional filtering, if-else ternary, matrix flattening/transposition, dict/set comprehensions, walrus operator `:=`, bytecode benchmarks |
| 16 | [generator_expressions.ipynb](generator_expressions.ipynb) | Generator Expressions | Lazy on-demand evaluation, $O(1)$ constant memory profiling, stream pipelines, built-in aggregator integration, one-time consumption rule |
| 17 | [programming_paradigms.ipynb](programming_paradigms.ipynb) | Programming Paradigms | Multi-paradigm architecture, Procedural, Functional (pure functions, immutability, `reduce`), OOP (encapsulation, polymorphism), Declarative (`match/case`), comparative solutions |
| 18 | [context_managers.ipynb](context_managers.ipynb) | Context Managers | `with` statement, `__enter__`/`__exit__` protocol, exception suppression, `@contextmanager`, `contextlib` tools (`suppress`, `redirect_stdout`, `ExitStack`), `async with`, atomic transactions |

---

## 🚀 How to Use

Launch Jupyter Lab in the root directory:
```bash
jupyter lab
```
And navigate into `learn_the_basics/` to run any notebook sequentially.
